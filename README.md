# AI 漫剧导演级分镜

将剧本、梗概或已有分镜转化为连续镜头设计的中文 Agent Skill，包含 120 种镜头技巧参考。

适合创作完整分镜、优化局部镜头、编写图生视频提示词，以及检查角色和镜头之间的连续性。技能输出文字方案；实际图片、视频、声音生成由相应工具完成。

## 使用方法

安装后，在聊天中明确要求使用 `ai-drama-storyboard`，并提供剧本或已有分镜。

```text
请使用 ai-drama-storyboard 技能，为下面的剧情设计连续分镜。

剧情：女主深夜回到旧宅，发现书房灯亮着。她推门，看到桌上有一封写着自己名字的信，窗户敞开，屋内无人。
要求：9:16 竖屏，悬疑气氛，总时长约 30 秒，保持剧情不变。
输出：分镜表，包括镜号、预计时长、景别/角度、画面与动作、运镜、声音、衔接及叙事作用，并给出总时长。
```

需要视频提示词时，再补充：

```text
请为每个镜头补充可单独复制的中文图生视频提示词。
人物以我提供的参考图为准；每镜一个主要动作，说明动作方向、起止状态、简单运镜和预计时长。
```

更多示例见 [examples/usage.md](examples/usage.md)，详细安装、更新和排错见 [docs/INSTALL.md](docs/INSTALL.md)。

## 主要能力

- 按人物目标、事件、情绪变化和信息揭示顺序拆分故事节拍。
- 设计景别、角度、构图、运镜、对话反打和镜头节奏。
- 输出可剪辑的分镜表，估算镜头与整段时长。
- 按需编写中文图生视频提示词。
- 检查服饰、道具、站位、视线、动作方向与光线的连续性。
- 标出难生成的复杂交互，并提出拆镜或后期剪辑方案。
